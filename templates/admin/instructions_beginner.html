📖 Инструкция по работе с админкой

Эта админка управляет сайтом с материалами для занятий. Ниже — пошаговое описание всех разделов и полей.

В левом меню админки вы видите пять разделов:

1

Категории

Меню → Категории → кнопка «Создать»

Категории группируют товары и определяют, в каком из трёх разделов сайта они появятся.

ПолеОписание
nameНазвание категории — оно будет видно на сайте. Пример: «Рабочие листы», «Диагностика»
Раздел менюОпределяет, под каким большим разделом появится категория:
• Дефектологам — для дефектологов
• Логопедам — для логопедов
• Подготовка к школе — для родителей и педагогов
product_typeТип товара — внутренняя метка для сортировки. Должен совпадать с product_type категорий по умолчанию (например worksheets, diagnostics, didactic_games)
💡 Совет: Если вы создаёте категорию «Рабочие листы» для дефектологов, используйте name = «Рабочие листы», Раздел меню = Дефектологам, product_type = worksheets.
⚠️ Важно: Поля product_type должно совпадать с тем, что ожидает API сайта. Список допустимых значений:
diagnostics, courses, didactic_games, documents, worksheets, workbooks, webinars, school_reading, school_letters, school_math, school_motor, school_writing, school_diagnostics, school_geometry

Управление товарами

Меню → Управление товарами → кнопка «Создать»

Здесь создаются карточки материалов, которые видят посетители сайта.

ПолеОписание
titleНазвание материала — заголовок карточки. Пример: «Рабочий лист «Алфавит»»
descriptionКраткое описание материала. Здесь можно указать возраст, цель, объём
priceЦена. Можно оставить пустым, если бесплатно
typeТип материала — внутренняя метка (аналогично product_type у категорий)
КатегорияВыберите категорию из списка. Именно она определяет, в каком разделе сайта появится карточка
Show contactsФлажок: если включён — на карточке будут видны контакты продавца
Изображение карточкиКартинка для превью. Форматы: PNG, JPG, JPEG, WEBP. Рекомендуемый размер: 400×400 или 600×400 пикселей
Файл товараСам материал для скачивания. Форматы: PDF, ZIP, DOC, DOCX. Макс. размер — 25 МБ

Порядок действий при добавлении товара:

  1. Заполните title и description
  2. Укажите цену (если есть) и тип
  3. Выберите категорию — это самый важный шаг
  4. Загрузите изображение карточки
  5. Загрузите файл товара (если это downloadable-материал)
  6. Нажмите «Save»
💡 Совет: Сначала загрузите файл и картинку — если загрузка не удалась, Flask-Admin покажет ошибку. Без изображения и файла карточка всё равно появится, но с заглушками.

Редактирование: Чтобы изменить товар, найдите его в списке (можно искать по названию или фильтровать по типу/флажку контактов), наведите на строку и нажмите иконку карандаша.

Просмотр карточки на сайте: Откройте http://ваш_сайт → выберите раздел меню → категорию → карточку товара.

Заявки (Лиды)

Меню → Заявки (Лиды)

Здесь отображаются все обращения, которые оставили посетители сайта через форму заказа.

ПолеОписание
nameИмя клиента
contactКонтакт (телефон, email или Telegram)
product_nameНазвание материала, который запросил клиент
dateДата и время обращения

Возможности:

  • Поиск по имени, контакту или названию товара (поле поиска сверху)
  • Сортировка по любому столбцу (клик по заголовку)
  • Экспорт в CSV: кнопка «Export» → CSV
  • Удаление заявок: отметьте чекбоксы → действие «Delete»
⚠️ Уведомления в Telegram: Если в «Настройках сайта» заполнены telegram_bot_token и telegram_chat_id, каждая новая заявка автоматически дублируется сообщением в ваш Telegram-чат.

Настройки сайта

Меню → Настройки сайта → карандаш (редактировать)

Здесь настраиваются контакты и интеграция с Telegram. Запись одна — нажмите карандаш для редактирования.

ПолеОписание
sale_modeРежим продаж: lead_form (форма заявки) или другой режим
admin_tg_usernameTelegram-username админа (например @misha). Используется для прямой ссылки
phoneТелефон для контактов
emailEmail для контактов и получения заявок
tg_usernameTelegram-username для отображения на сайте
tg_linkПолная ссылка на Telegram-канал/личку (например https://t.me/your_username)
hero_image_pathИмя файла большой картинки в шапке сайта
Изображение шапкиЗагрузить новую картинку для hero-секции (PNG/JPG/WEBP)
SMTP HostАдрес SMTP-сервера. Для Gmail: smtp.gmail.com, для Яндекс: smtp.yandex.ru, для Mail.ru: smtp.mail.ru
SMTP PortПорт SMTP-сервера. Обычно 587
SMTP LoginПолный email-адрес для входа (например my@gmail.com)
SMTP PasswordПароль приложения для SMTP (не основной пароль от почты!)
SMTP Use TLSВключите TLS-шифрование (оставьте включённым по умолчанию)

Настройка Telegram-уведомлений:

  1. Откройте бота @BotFather в Telegram
  2. Отправьте команду /newbot и следуйте инструкциям
  3. Скопируйте API-токен (вида 123456:ABC-DEF...)
  4. Вставьте токен в поле telegram_bot_token
  5. Напишите боту любое сообщение
  6. Откройте https://api.telegram.org/botТОКЕН/getUpdates в браузере
  7. Найдите в ответе "chat":{"id":-123456789} — это ваш telegram_chat_id
  8. Вставьте ID в поле telegram_chat_id
🚫 Не меняйте поля telegram_bot_token и telegram_chat_id без необходимости — неправильное значение сломает уведомления.

📧 Настройка пересылки заявок на email

Чтобы заявки с сайта приходили на ваш email, настройте SMTP-подключение. Это безопаснее, чем указывать обычный пароль — используется пароль приложения.

Шаг 1. Выберите почтовый сервис:

СервисSMTP HostSMTP Port
Gmailsmtp.gmail.com587
Яндекс.Почтаsmtp.yandex.ru587
Mail.rusmtp.mail.ru587

Шаг 2. Создайте пароль приложения:

Для Gmail

  1. Откройте Google Аккаунт
  2. Перейдите в раздел Безопасность
  3. Включите двухфакторную аутентификацию (если не включена)
  4. Снова откройте Безопасность
  5. Найдите раздел Пароль приложения (в разделе «Вход в Google»)
  6. В поле «Выберите приложение» выберите Другое (название)
  7. Введите название, например: Сайт
  8. Нажмите Создать
  9. Скопируйте появившийся 16-символьный код (например abcd efgh ijkl mnop)
🚫 Не вводите обычный пароль от Gmail! Нужен именно пароль приложения. Без него SMTP не заработает.

Для Яндекс.Почта

  1. Откройте Аккаунт Яндекса
  2. Перейдите в Безопасность
  3. Включите двухфакторную аутентификацию
  4. Откройте раздел Пароли приложений
  5. Создайте новый пароль для «Другого приложения» — назовите Сайт
  6. Скопируйте появившийся пароль

Для Mail.ru

  1. Откройте Mail.ru
  2. Нажмите на аватар → Пароль и подключение
  3. Перейдите в Пароли приложений
  4. Создайте новый пароль — назовите Сайт
  5. Скопируйте появившийся пароль

Шаг 3. Введите данные в админке:

ПолеЧто вписатьПример
EmailКуда слать заявкиmy@gmail.com
SMTP HostАдрес SMTP из таблицы вышеsmtp.gmail.com
SMTP PortПорт (обычно 587)587
SMTP LoginВаш email полностьюmy@gmail.com
SMTP PasswordПароль приложения (16 символов)abcdefg hijklmnop
SMTP Use TLSОставьте включённым☑️

Шаг 4. Проверьте:

  1. Нажмите Сохранить
  2. Оставьте тестовую заявку на сайте (через форму заказа)
  3. Проверьте почту — должно прийти письмо с темой «🚨 Новая заявка: ...»
⚠️ Если email не приходит:
  • Проверьте, что Email не равен info@example.com — это значение по умолчанию
  • Убедитесь, что введён именно пароль приложения, а не обычный пароль от почты
  • Проверьте логи Flask — там будет ошибка SMTP, если что-то не так
  • Для Gmail: убедитесь, что в настройках аккаунта разрешены «менее безопасные приложения» (лучше включить 2FA)
💡 Заявки сохраняются всегда — даже если SMTP не настроен, заявки будут записываться в базу данных и отображаться в разделе «Заявки (Лиды)». Просто email не уйдёт.
