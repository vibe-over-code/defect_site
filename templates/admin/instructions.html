📖 Инструкция по управлению сайтом

1️⃣ Добавление категорий

Категории — это разделы, по которым пользователи фильтруют материалы.

  • name — название категории (отображается в фильтрах)
  • product_type — тип материалов в этой категории:
    • diagnostics — Диагностика
    • workbooks — Рабочие тетради
    • courses — Программы коррекционных курсов
    • didactic_games — Дидактические игры
    • documents — Документы
    • worksheets — Рабочие листы

⚠️ Важно: При создании категории «Дефектологам» или «Логопедам» обязательно установи product_type = courses, иначе они не появятся в фильтре программ курсов.

2️⃣ Добавление товаров (материалов)

Каждый товар — это карточка, которую увидит пользователь на сайте.

  • title — название материала
  • description — краткое описание
  • price — цена (оставь пустым, если бесплатно)
  • type — тип материала (совпадает с product_type категорий)
  • category — выбери категорию из списка
  • show_contacts:
    • ✅ Включено — пользователь увидит контакты и кнопку «Связаться» + скачает файл
    • ❌ Выключено — откроется форма заявки

2.1 Загрузка файла товара

При создании или редактировании товара есть поле «Файл товара»:

  • Нажми «Выберите файл» и загрузи PDF, ZIP или DOC
  • Файл автоматически сохранится в папку uploads/
  • Путь к файлу заполнится автоматически
  • Если файл с таким именем уже есть — добавится суффикс _1, _2 и т.д.

✅ После сохранения товара файл будет доступен по ссылке на сайте.

4️⃣ Заявки (Лиды)

Здесь отображаются все заявки, оставленные пользователями через форму на сайте.

  • name — имя пользователя
  • contact — Telegram или телефон
  • product_name — какой товар интересовал
  • date — дата и время заявки

5️⃣ Настройки Сайта

Здесь настраиваются контакты и уведомления:

  • phone — номер телефона для отображения
  • email — email для отображения
  • tg_username — никнейм Telegram для отображения
  • tg_link — полная ссылка на Telegram-канал/личку
  • telegram_bot_token — токен от @BotFather (для уведомлений в Telegram)
  • telegram_chat_id — ваш ID чата (куда будут приходить уведомления)

🔧 Как получить токен и ID:

  1. Напишите @BotFather → /newbot → скопируйте токен
  2. Напишите @userinfobot → скопируйте ваш ID
  3. Вставьте оба значения в настройки и нажмите «Сохранить»
⚠️ Важно: После добавления товаров через админку они сразу появляются на сайте. Не нужно перезагружать сервер.
